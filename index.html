ThinkCentre Plex Music

A private, single-owner music server project. It connects the owner's Google Drive music folder to rclone and a self-hosted Plex Media Server on the owner's Oracle Cloud VPS (with the earlier ThinkCentre installation retained as a fallback), for listening with Plexamp.

This is not a public music service. Google sign-in is intended only for the owner. Google Drive access is read-only. Music originals stay in Google Drive; the server reads requested files and keeps a limited local playback cache, alongside Plex's music metadata.

The Oracle deployment uses HTTPS and Plex account authentication. The server reads the selected Drive music folder on demand; it does not synchronize the whole music collection.
